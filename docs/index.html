Cost

See where your tokens go and how to spend fewer.

The Improvements tab reads your last 30 days and ranks what to change: lighter models for quick tasks, fresh sessions, cache misses, startup context. Each one comes with an estimated monthly saving. Set daily, weekly or monthly budgets and get a notification at 80% and 100%.

Costs are estimated at API list prices. On Pro or Max you aren't billed per token, so read them as how hard you're using your plan.

Know what's running.

Every session shows working or idle, and a context meter tells you when to /compact. The ✦ in the menu bar keeps it all one click away, even with the window closed. Turn on approvals and answer "can I run this?" from a notification. Ignore it and the terminal asks as usual.

Everything it touches.

Claudeck has no backend. This is the full list.

Reads
~/.claude
Sessions, settings, skills, plugins and file history.
Writes
~/Documents/Claudeck
Memory docs and digests.
~/Library/Application Support/Claudeck
App data.
~/.claude
Settings, only when you change something. A *.claudeck.bak backup is saved first.
Network
None of its own.
The only traffic comes from Claude Code runs you start. AI summaries and digests count as those runs, and they aren't saved as sessions.

3
The first time, right-click the app and choose Open.
Claudeck is ad-hoc signed but not notarized yet, so macOS says it can't verify the developer. Right-click, choose Open, then Open again. On macOS 15 and later, go to System Settings → Privacy & Security and click Open Anyway. You only do this once.
